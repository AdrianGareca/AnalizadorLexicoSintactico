Recorrido

Laboratorio de la pila

Escribe solo delimitadores, o un fragmento con cadenas y comentarios. Los paréntesis que estén dentro de un texto no entran a la pila.

Autómata de pila

P = (Q, Σ, Γ, δ, q, Z₀, {qf})
Q = { q, qf }
Σ = { (, ), [, ], {, } }
Γ = { (, [, {, Z₀ }
Aceptación: al consumir la entrada, δ(q, ε, Z₀) = (qf, Z₀).

Transiciones, con X cualquier símbolo de la pila:

  • δ(q, '(', X) = (q, '( X) y lo mismo para '[' y '{'.
  • δ(q, ')', '(') = (q, ε). Igual para ']' con '[' y '}' con '{'.
  • Un cierre que no coincide con el tope no tiene transición: la cadena se rechaza.
  • ';' y ',' son separadores del lenguaje. No pertenecen a Σ de esta pila.

El autómata no ve comentarios ni el interior de las cadenas. Esa separación la hace el mismo recorrido que usa el analizador léxico, para que un paréntesis escrito dentro de un texto no se confunda con uno del programa.

El laboratorio exige que toda la cadena termine en un estado de aceptación. El analizador léxico, en cambio, se queda con el prefijo más largo que haya pasado por un estado final y deja el resto para el token siguiente. Por eso 12. se rechaza aquí y, en el editor, se parte en el número 12 y un punto erróneo.

Operadores

          
Se reconocen con munch máximo: si dos caracteres forman un operador, ese lexema gana sobre dos operadores de un carácter. Así == no se parte en = =, ni >= en > =.

          
El signo de un número no entra al AFD de números. -3 son dos tokens: el unario - y el entero 3. Las conectivas del lenguaje son las palabras and, or y not.
